Como usar o StreamCanvas

Visão geral

O Host cria uma sala e compartilha o código. Convidados entram, adicionam elementos (imagens, vídeos, textos) que aparecem em tempo real na tela do Host — ideal para overlays de live.

Toolbar (barra lateral esquerda)

  • Imagem / GIF / Vídeo — escolha um arquivo ou arraste direto na tela. A posição do drop é respeitada.
  • Texto — texto simples. Dê duplo-clique depois para editar em tempo real.
  • YouTube — cole um link (aceita minutagem, ex: ?t=135).
  • Áudio — vira uma barra com play, progresso e volume. O Host toca o som na live.
  • HTML — cola código HTML que roda em um painel. Apenas uma instância por vez.
  • Pincel / Borracha — desenho livre sobre a tela.
  • Programar — cria presets de cena acionados por teclas 1-0 (veja abaixo).
  • Desfazer / Refazer / Limpar — histórico.

Editando um elemento

Clique para selecionar. Arraste para mover. Use os handles:

  • Handle verde (canto inferior esquerdo) — arrastar
  • Handle azul (canto inferior direito) — redimensionar (segure SHIFT para esticar/amassar)
  • Handle roxo (acima) — rotacionar
  • Botão vermelho (canto superior direito) — remover

Duplo-clique em qualquer elemento abre o painel completo: opacidade, play/mute, loop, ocultar, barra de posição, volume, hotkeys e cor (para texto).

Ocultar do Host

No painel de duplo-clique, use Ocultar. O elemento fica invisível apenas para o Host (o som continua), enquanto convidados ainda o veem. Útil para pré-visualizar antes de mostrar.

Área visível do Host

O quadro pontilhado no meio da tela mostra exatamente o que aparece no Host/OBS. Tudo que estiver fora dele fica só na sua tela — uma área de "bastidores" pra preparar elementos sem precisar excluí-los. Arraste um elemento pra fora do quadro pra escondê-lo do Host, e de volta pra dentro pra mostrá-lo.

Use o scroll do mouse para dar zoom in/out (com o cursor como centro) e arraste o fundo vazio da tela para navegar. Dê duplo-clique no fundo ou use o botão Ajustar zoom na toolbar para voltar à visão normal.

Hotkeys 1-0

Em imagens, GIFs, vídeos e YouTube, associe até 10 arquivos/links diferentes. Pressione a tecla correspondente para trocar. Pressionar a mesma tecla de novo oculta o elemento (toggle).

Programar (presets de cena)

Clique em Programar na toolbar, escolha um slot (1-0) e comece a adicionar elementos. Eles aparecem como ghosts (semitransparentes). Posicione à vontade. Ao clicar Sair, o conjunto é salvo.

Depois, com a tela normal, pressione a tecla do slot: todos os elementos aparecem de uma vez. Pressione de novo para esconder. Você pode ter até 10 programas diferentes.

Mostrar mouse

Ative Mouse na toolbar para que os convidados vejam seu cursor virtual com nome e cor, com animação suave. Clicar na tela mostra um efeito de click para todos.

Live do Daenil

Botão no canto superior esquerdo: incorpora a live do canal Daenil em tela cheia. Clique de novo para esconder.

Atalhos

  • C (Host) — copia o código da sala
  • ESC — sai da sala / volta ao menu
  • 1 a 0 — hotkeys e programas

Programar

Escolha um slot. Você entra em modo edição e qualquer coisa que adicionar vira parte do preset. Ao sair, tudo é salvo. Depois use as teclas 1-0 para mostrar ou esconder o conjunto.
